## 🚀 Como Ativar no GitHub Pages

Este repositório está configurado para publicação estática instantânea (Zero Cost & Fastly CDN):

1. Acesse o repositório no GitHub: `https://github.com/Techdimbr/techdimbr`
2. Vá em **Settings** > **Pages**
3. Em **Branch**, selecione `main` e a pasta `/ (root)`
4. Clique em **Save**
5. O site estará online imediatamente em `https://techdimbr.github.io/` (ou no domínio personalizado configurado em `Settings > Custom domain`).
