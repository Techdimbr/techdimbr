## 2026-10-14 - Interactive Elements Accessibility & Dynamic Updates
**Learning:** Required form fields need semantic indicators (`aria-required="true"`) to be properly identified by screen readers, and replacing non-semantic elements (`div`) with native ones (`button`) for interactions like copy-to-clipboard ensures proper focusability. In addition, dynamically injected alerts like custom toasts must explicitly define `role="status"` and `aria-live="polite"` so they are announced when they appear without interrupting the user.
**Action:** Always use native semantic elements for interactive triggers (`<button type="button">`), mark required inputs explicitly with `aria-required`, and consistently add proper ARIA live region attributes to UI feedback components like toasts.
