Notícia de tecnologia 24 de outubro de 2026

Windows Server 2016: Microsoft avisa que a atualização de janeiro de 2027 será a última

A Microsoft avisou que a atualização de segurança de janeiro de 2027 será a última do Windows Server 2016. Depois dela, o servidor deixa de receber as correções mensais de segurança.

Em resumo

  • A Microsoft confirmou que a atualização de segurança de janeiro de 2027 será a última do Windows Server 2016, em todas as edições, inclusive a Essentials
  • Depois disso, o sistema deixa de receber as atualizações mensais de segurança. O suporte aos recursos exclusivos do Essentials, como o Remote Web Access, também termina
  • Na sua empresa: liste os servidores com Windows Server 2016 e planeje a migração. A Microsoft recomenda o Windows Server 2025, com teste gratuito de 180 dias

Quantos servidores da sua empresa ainda rodam Windows Server 2016? Faça o levantamento agora, para migrar sem correria.

Por que importa

Notícia de 23/10 confirmada no BleepingComputer e na página de ciclo de vida da Microsoft: o Windows Server 2016 recebe a última atualização de segurança em janeiro de 2027, com impacto direto em servidores de pequenas e médias empresas.

O que fazer na prática

  1. Faça o inventário. Liste cada servidor com Windows Server 2016, o que roda nele e quem depende dele.
  2. Escolha o destino. A Microsoft recomenda o Windows Server 2025. Teste os sistemas da empresa antes de migrar.
  3. Marque a data. A última atualização será a de janeiro de 2027: planeje a migração com folga, não na última semana.
