## 2026-10-15 - Semantics in Interactive Elements and Dynamic Roles
**Learning:** Found a common pattern where `div` and `span` were used for interactive elements (like the 'Copy Email' action and dynamic slider outputs). Custom interactive elements like a clickable div lack automatic keyboard focus and `Space/Enter` key trigger events without custom JS handling. Furthermore, dynamic toast notifications added to the DOM won't be announced to screen readers unless they contain specific aria attributes like `role="status"` or `aria-live`.
**Action:** Always prefer native semantic elements like `<button type="button">` over `<div>` with click handlers. Ensure dynamically injected content like Toasts and dynamic badges have proper ARIA live region definitions (`role="status"` or `aria-live="polite"`) to announce state changes correctly to assistive technologies.
